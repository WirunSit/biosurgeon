# BioSurgeon: ศัลยแพทย์ชีววิทยา

เกมจำลองการผ่าตัด 3 มิติสำหรับชีววิทยา ม.ปลาย ตามแผนใน `../biosurgeon-plan.md`
9 ระบบร่างกาย × 2 เคส + ด่าน 0 ฝึกพื้นฐาน — เล่นได้ครบทั้ง 19 ด่าน
ล็อบบี้ → แฟ้มผู้ป่วย/สืบสวน → วินิจฉัย → เตรียมผ่าตัด → ผ่าตัด 3 มิติ → หลังผ่าตัด → สรุปคะแนน

## วิธีรัน

ต้องมี Node.js 18 ขึ้นไป

```bash
npm install
npm run dev
```

เปิด `http://localhost:5173` (ใช้ `--host` อยู่แล้ว เครื่องอื่นในวง LAN เดียวกันเปิดผ่าน IP ของเครื่องครูได้)

สร้างไฟล์สำหรับเผยแพร่ (GitHub Pages / Netlify / Vercel หรือโฟลเดอร์แชร์ในห้องคอม):

```bash
npm run build
```

ผลลัพธ์อยู่ในโฟลเดอร์ `dist/` ใช้พาธแบบ relative จึงวางไว้ในโฟลเดอร์ย่อยใดก็ได้
(ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ ดับเบิลคลิก `index.html` ตรง ๆ จะโหลดไฟล์เคสไม่ได้)

คู่มือสำหรับครู (ติดตั้ง Google Sheets, ลิงก์ห้องเรียน, ลำดับการสอน, แบบทดสอบ): `teacher/คู่มือครู.md`

## การเพิ่ม/แก้เคส

ทุกเคส (ยกเว้น 1.1) ใช้ฉากทั่วไป `"scene": "field"` ซึ่งสร้างจากข้อมูลใน `surgery.field` ทั้งหมด จึงเพิ่มเคสได้โดยไม่ต้องแก้โค้ด

1. คัดลอกเคสที่คล้ายกันใน `public/cases/` เป็นไฟล์ใหม่ (ชนิดข้อมูลทั้งหมดอยู่ใน `src/types.ts`)
2. แก้ข้อมูลผู้ป่วย ประวัติ ตรวจร่างกาย ผลตรวจ วินิจฉัย ขั้นตอนผ่าตัด และคำถาม
3. ใน `public/cases/index.json` ตั้ง `"available": true`
4. ทดสอบด้วยตัวเล่นอัตโนมัติ (ด้านล่าง) และลองเล่นจริงด้วยเมาส์

**ฉาก field** — พิกัด `[u, v, d]` (เมตร): u = ไปทางซ้ายของผู้ป่วย, v = ไปทางเท้า, d = ลึกจากผิว
- `window.hw` กำหนดสเกลทั้งฉาก (ตา ≈ 0.02, ช่องท้อง ≈ 0.075), `center` = ตำแหน่งบนลำตัว
- `layers` ชั้นเนื้อเยื่อ เปิดเป็นช่องรูปเลนส์ตามแนว `paths` (หรือวงกลมด้วย `circle`)
- `objects` รูปทรง: ellipsoid sphere tube box cylinder torus disc stones ring lens sheet; `inside: true` = มองจากด้านใน (อุโมงค์กล้องส่อง), `hit` = ขยายรัศมีคลิก, `parent` = เป็นส่วนของวัตถุอื่น, `model` = ไฟล์ .glb (ระยะ 2)
- `cameras` มุมกล้องพิเศษ: `pos=[u, สูงเหนือผิว (ติดลบ = ใต้ผิว), v]`, `target=[u, ลึก, v]`

**action ของขั้นตอน:** scrub, trace, click, hold, drag, sequence, suture, choice, rotate, minigame
**effect** (onStart/onSuccess/mistakes.effects): `open:<ชั้น>:<กว้าง>` `close:` `show:` `hide:` `move:<id>:du:dv:dd` `rotate:` `color:<id>:#hex` `opacity:` `scale:` `emissive:` `pool:` `pulse:` `remove:` `label:` `attach:<เครื่องมือ>:<เป้า>` `detach:` `camera:<ชื่อ>|field` `dress` `trail` และที่ห้องผ่าตัดจัดการเอง `recover[:k]` `scope:on|off` `base:HR|BP|SpO2|RR:<ค่า>` `stopbleed`

**ข้อควรรู้เวลาวางวัตถุ**
1. กล้องมองจากทางเท้าลงมา วัตถุที่ลึก d จะเห็นผ่านผิวที่ตำแหน่ง v + 0.39·d → วางอวัยวะเลื่อนไปทาง −v และให้อยู่ในช่องเปิดของชั้นล่างสุด (ช่องรูปเลนส์ กว้างสุดตรงกลาง เรียวที่ปลาย)
2. วัตถุที่ต้องคลิกต้องไม่ถูกวัตถุอื่นบัง — ตรวจด้วย `__bs.probe()`
3. จุดเย็บ (suture) ต้องอยู่ในช่องเปิดของชั้นเหนือขึ้นไป
4. เหตุการณ์ "รอนานเกิน" (`events`) ควรตั้ง threshold ให้มากกว่าเวลาที่ใช้เก็บเบาะแสครบ (ราว 1.5 เท่า)

## การทดสอบ (โหมดพัฒนาเท่านั้น)

- `http://localhost:5173/?autoplay=<id>` หรือในคอนโซล `await __bs.autoplay('<id>')` → เล่นตามคำตอบที่ถูกทุกข้อ แล้วรายงาน "✔ จบเคส" หรือ "✘ ติดที่ขั้น…" (คืนค่าข้อมูลผู้เล่นเดิมหลังทดสอบ)
- `await __bs.autoplay('<id>', '<step id>')` หยุดก่อนขั้นที่ระบุ ค้างฉากไว้ให้ตรวจ แล้วใช้ `__bs.probe()` ดูว่าคลิกที่วัตถุแต่ละชิ้นแล้วโดนอะไร
- `__bs.sm.step(dt)` เดินเฟรมเอง (จำเป็นเมื่อแท็บถูกซ่อนแล้ว requestAnimationFrame หยุด)
- ตัวเล่นอัตโนมัติส่ง pointer event ตรงเข้าแคนวาส จึงไม่จับปัญหาชั้น UI บังคลิก — ต้องลองเล่นจริงด้วย
- ตรวจชนิดข้อมูล: `npx tsc --noEmit`, build: `npm run build`

## ระยะ 2: โมเดลอวัยวะจาก Z-Anatomy

```bash
blender Z-Anatomy.blend --background --python blender_scripts/extract_organs.py -- blender_scripts/organs.csv public/models/organs
```

- `organs.csv` คอลัมน์: case_id, object_id, z_anatomy_name, max_tris, color, out_file
- ชื่อใน `z_anatomy_name` เป็นชื่อภาษาอังกฤษตามศัพท์กายวิภาค — **ต้องตรวจกับ Outliner ของไฟล์ Z-Anatomy ก่อนรัน** (สคริปต์รองรับการจับคู่ชื่อแบบขึ้นต้นด้วย และจะพิมพ์ "ไม่พบ" ถ้าหาไม่เจอ) ใช้ `|` คั่นเพื่อรวมหลายชิ้นเป็นชิ้นเดียว
- ไฟล์ .glb ชิ้นเดียวใช้ได้หลายเคส (เช่น stomach.glb ใช้ในเคส 4.2 และ 8.2) — ใส่ `"model": "models/organs/<ไฟล์>"` ให้วัตถุในไฟล์เคส ถ้าไม่มีไฟล์ เกมจะใช้รูปทรงพื้นฐานเดิม
- อวัยวะที่เป็นท่อ (หลอดเลือด ท่อ เอ็น) และชิ้นที่ต้องตัด/แยก (กระดูกหัก) ยังใช้รูปทรงพื้นฐาน
