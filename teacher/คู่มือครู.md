# คู่มือครู — BioSurgeon: ศัลยแพทย์ชีววิทยา

เกมจำลองการผ่าตัด 3 มิติ สำหรับรายวิชาชีววิทยา ม.4–ม.6
นักเรียนรับบทแพทย์ฝึกหัด: ซักประวัติ ตรวจร่างกาย สั่งตรวจ วินิจฉัย ผ่าตัด แล้วตอบคำถามชีววิทยาที่เชื่อมกับเคส

> เกมนี้เป็นสื่อการเรียนรู้ชีววิทยา **ไม่ใช่การฝึกทางการแพทย์** ขั้นตอนผ่าตัดถูกทำให้ง่ายลงและค่าตัวเลขเป็นค่าประมาณ

## 1. เตรียมก่อนสอน (ทำครั้งเดียว)

### 1.1 เลือกวิธีเปิดเกม
| วิธี | เหมาะกับ | ขั้นตอน |
|---|---|---|
| เว็บไซต์ (แนะนำ) | ห้องคอม / Chromebook / แท็บเล็ต / มือถือ | นำโฟลเดอร์ `dist/` (ได้จาก `npm run build`) ขึ้น GitHub Pages, Netlify หรือ Vercel แล้วแจกลิงก์ |
| เครื่องครูในวง LAN | ห้องที่ไม่มีอินเทอร์เน็ตแต่มี Wi-Fi ภายใน | เครื่องครูรัน `npm run dev` นักเรียนเปิด `http://<IP เครื่องครู>:5173` |
| โฟลเดอร์แชร์ | ห้องคอมที่มีเว็บเซิร์ฟเวอร์ภายใน | วางโฟลเดอร์ `dist/` บนเซิร์ฟเวอร์ (ดับเบิลคลิก `index.html` ตรง ๆ ใช้ไม่ได้) |

ทดสอบบนเครื่องที่นักเรียนใช้จริงอย่างน้อย 1 เครื่องก่อนคาบแรก — เปิดเคสใดก็ได้แล้วเล่นจนถึงห้องผ่าตัด

### 1.2 เปลี่ยนรหัสครู
ล็อบบี้ > ปุ่ม **โหมดครู** > ใส่รหัสเริ่มต้น `1234` > แท็บ **ตั้งค่าห้องเรียน** > ช่อง "รหัสครู" ใส่รหัสใหม่
(รหัสเก็บในเบราว์เซอร์ของเครื่องนั้น ถ้าใช้หลายเครื่องต้องตั้งทุกเครื่อง)

### 1.3 ส่งคะแนนเข้า Google Sheets (ไม่บังคับ)
ถ้าไม่ตั้ง คะแนนจะเก็บเฉพาะในเครื่องที่เล่น (ดูได้ในโหมดครู > ผลการเรียน และส่งออก CSV ได้)

1. สร้าง Google Sheets ใหม่ 1 ไฟล์ต่อ 1 ภาคเรียน (หรือ 1 ไฟล์ต่อห้อง)
2. เมนู **ส่วนขยาย > Apps Script** ลบโค้ดเดิม วางโค้ดทั้งหมดจากไฟล์ `teacher/apps-script.gs` แล้วกดบันทึก
3. **ทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่** > เลือกประเภท **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
4. กดอนุญาตสิทธิ์ (ครั้งแรก Google จะเตือนว่าแอปยังไม่ได้รับการยืนยัน ให้กด "ขั้นสูง" > "ไปที่โปรเจกต์")
5. คัดลอก URL ที่ลงท้ายด้วย `/exec` ไปใส่ในเกม: โหมดครู > ตั้งค่าห้องเรียน > "URL ของ Google Apps Script"
6. ทดสอบ: เล่นด่าน 0 ให้จบ 1 รอบ แล้วดูว่ามีแถวใหม่ในแผ่นงาน "ผลการเรียน"

ข้อมูลที่ส่ง: เวลา รหัสห้อง เลขที่/ชื่อเล่น เคส ระดับความยาก คะแนนแต่ละหมวด เวลา เลือดที่เสีย และรายการข้อผิดพลาด
**ไม่มีชื่อ-นามสกุลจริง เลขประจำตัวประชาชน หรืออีเมล** — แนะนำให้นักเรียนใส่ "เลขที่" แทนชื่อ

## 2. ลิงก์ห้องเรียน

ในโหมดครู > ตั้งค่าห้องเรียน ตั้งค่าแล้วคัดลอก **ลิงก์สำหรับแจกนักเรียน** ไปวางใน Google Classroom / LINE กลุ่มห้อง
นักเรียนเปิดลิงก์แล้วเกมจะตั้งค่าห้องให้อัตโนมัติ ตัวอย่าง:

```
https://<เว็บของครู>/?class=ม5-1&sheet=<URL /exec>&stages=0,1,2&difficulty=easy
```

| พารามิเตอร์ | ความหมาย |
|---|---|
| `class` | รหัสห้อง (แสดงในคะแนนที่ส่งเข้า Sheets) |
| `sheet` | URL ของ Apps Script จากข้อ 1.3 |
| `stages` | ด่านที่เปิดให้เล่น คั่นด้วยจุลภาค (0 = ฝึกพื้นฐาน, 1–9 = ระบบร่างกาย) |
| `difficulty` | `easy` ไฮไลต์เป้าหมาย / `normal` บอกแค่คำสั่ง / `challenge` ต้องจำขั้นตอนเอง |

ตัวเลือกเพิ่มเติมในโหมดครู: "ต้องผ่านด่านก่อนหน้าก่อน" (ปลดล็อกทีละด่าน) และ "ปลดล็อกทุกเคสในเครื่องนี้" (สำหรับเครื่องครูที่ใช้สาธิตหน้าห้อง)

## 3. โครงสร้างหนึ่งเคส (ใช้เวลาประมาณ 20–30 นาที)

1. **แฟ้มผู้ป่วย/สืบสวน** — ถามประวัติ ตรวจร่างกาย สั่งตรวจ ทุกอย่างกินเวลาในเกม บางเคสถ้าช้าเกินผู้ป่วยจะทรุด (ไส้ติ่งแตก ม้ามแตก ก้อนเลือดในสมองโตขึ้น อัณฑะขาดเลือด ฯลฯ) และงบตรวจมีจำกัด จึงต้องเลือกตรวจที่ให้ข้อมูลจริง
2. **วินิจฉัย** — เลือกโรคพร้อมหลักฐานจากสมุดบันทึก แล้วตอบคำถามชีววิทยา
3. **เตรียมผ่าตัด** — เลือกวิธีระงับความรู้สึก จัดถาดเครื่องมือ (มีเครื่องมือหลอก) และมินิเกมเฉพาะเคส
4. **ผ่าตัด 3 มิติ** — ทำตามขั้นตอน มีป้าย "ความรู้ชีววิทยา" หลังแต่ละขั้น ความผิดพลาดจะมีคำอธิบายผลทางชีววิทยา
5. **หลังผ่าตัด** — คำแนะนำผู้ป่วยและ Quiz 3 ข้อ
6. **สรุปคะแนน** 100 คะแนน: วินิจฉัย 30 / ผ่าตัด 25 / ความปลอดภัย 20 / ชีววิทยา 20 / เวลา 5 → 1–5 ดาว

## 5. การประเมินผล

- **คะแนนในเกม** — ดูรายบุคคลได้ใน Google Sheets หรือโหมดครู > ผลการเรียน (ส่งออก CSV) ใช้เป็นคะแนนเก็บได้ เช่น นับ 3 ดาวขึ้นไปเป็นผ่าน
- **แบบทดสอบก่อน-หลังเรียน** — `teacher/แบบทดสอบก่อน-หลังเรียน.md` 9 ระบบ ระบบละ 5 ข้อ ใช้ชุดเดียวกันทั้งก่อนและหลัง (ทำก่อนเริ่มระบบนั้น และหลังเล่นเคสของระบบนั้นครบ)
  คำนวณพัฒนาการ: `(คะแนนหลัง − คะแนนก่อน) / (คะแนนเต็ม − คะแนนก่อน) × 100%`
- **แบบสอบถามความพึงพอใจ** — `teacher/แบบสอบถามความพึงพอใจ.md` ทำครั้งเดียวหลังเล่นจบช่วงที่กำหนด
- แนะนำให้นำแบบทดสอบและแบบสอบถามไปสร้างเป็น Google Forms เพื่อสรุปผลอัตโนมัติ

## 6. ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| หน้าจอขาว/โหลดเคสไม่ได้ | ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (ไม่ใช่ดับเบิลคลิกไฟล์) และใช้ Chrome/Edge รุ่นใหม่ |
| ภาพกระตุก | เกมลดความละเอียดอัตโนมัติเมื่อเฟรมเรตต่ำ ปิดแท็บอื่น หรือใช้จอเล็กลง |
| คะแนนไม่เข้า Google Sheets | ตรวจว่า URL ลงท้าย `/exec` และตั้ง "ผู้ที่มีสิทธิ์เข้าถึง: ทุกคน" ถ้าแก้โค้ด Apps Script ต้อง Deploy เวอร์ชันใหม่ |
| นักเรียนเห็นเคสไม่ครบ | ตรวจพารามิเตอร์ `stages` ในลิงก์ และตัวเลือก "ต้องผ่านด่านก่อนหน้าก่อน" |
| นักเรียนไม่สบายใจกับภาพเลือด | ในล็อบบี้เปิด "โหมดลดความสมจริง" (เลือดเป็นสีฟ้าพาสเทล) |
| ลืมรหัสครู | ล้างข้อมูลเว็บไซต์ (site data) ของเกมในเบราว์เซอร์นั้น รหัสจะกลับเป็น `1234` (ผลการเรียนในเครื่องจะหายด้วย แต่ข้อมูลใน Sheets ยังอยู่) |
